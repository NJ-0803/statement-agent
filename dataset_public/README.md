# dataset_public

This folder contains a mix of (fictional) personal financial documents for the
challenge. Everything here is synthetic mock data.

```
statements/   bank & credit-card statements (PDF)
expenses/     exported expense/reimbursement sheets (CSV)
```

Notes:
- Formats, layouts, date formats and currency notations are intentionally inconsistent
  across files -- just like real life.
- Some documents may be harder to read than others.
- Amounts are in INR unless a transaction says otherwise.

Build something that can make sense of all of it. Good luck.
